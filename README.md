# Redline FC — Windows releases

Official Windows downloads and the public update feed for Redline FC. The game source is maintained separately.

## Download

[Get the latest release](https://github.com/ReviveRC/Redline-FC-Releases/releases/latest)

- **Setup EXE (recommended):** installs the game and supports automatic updates.
- **Portable EXE:** runs without installation; new versions are downloaded manually.
- **Windows ZIP:** includes both EXEs, the guide, checksums, and release metadata.

Requires 64-bit Windows 10 or 11. Single-player works offline. Career Together uses a host-to-partner connection.

## Automatic updates

Installed copies check GitHub after launch and every six hours. New stable releases download in the background. Use **Settings → Windows app → GitHub updates → Restart & install** when ready. Finish or leave the current fixture and disconnect Career Together first. Updates never install merely because you quit.

Portable copies check for new versions and link to the release page for manual replacement. Install the Setup version for automatic installation.

## Saves and settings

Use **Settings → Save backups** to export/import careers between the browser and Windows app. Saves live in `%APPDATA%\Redline FC` and remain through upgrades. Export backups before moving computers.

The game includes graphics presets, rendering resolution, FPS caps and overlay, particles, shadows, trails, crowd detail, brightness/contrast, accessibility options, controller deadzone, and native window/display settings.

## Release integrity

`SHA256SUMS.txt` lists release-file checksums. The builds are currently unsigned. Only stable releases with matching update metadata are offered by the in-game updater.
